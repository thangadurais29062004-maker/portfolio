Real-Time Fraud Detection Pipeline

Kafka streams transactions to Spark, which adds per-user 5-minute features, and an XGBoost model (best PR-AUC 0.695 among 3 models) scores each one as allow, review or block.

Results are stored in PostgreSQL and Redis with a live Streamlit dashboard. On held-out data it flagged 75% of fraud, with the block zone 79% fraud.

TruthLens AI: Image Verification App

A local web app that classifies images as likely real, likely AI-generated, or uncertain, using a Vision Transformer (ViT-Small) exported to ONNX.

An abstention policy scores each image three ways and only gives a verdict when all agree: 92.4% accuracy on the 448 of 600 images it decided. Includes EXIF, recompression, face and C2PA checks, user accounts, a job queue, PDF/JSON reports, Docker Compose with Caddy HTTPS, and 48 unit tests.
